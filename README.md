# Rock Paper Scissors — CLI (Python)

A very small command-line Rock Paper Scissors game written in Python.

## Requirements
- Python 3.7+

## Run
1. Make sure you have Python installed.
2. Run the game:
```bash
python rps.py
```

## How it works
- You will be asked to choose a "best of" (odd number of rounds). Default is 3.
- Enter a move each round: `r` / `rock`, `p` / `paper`, `s` / `scissors`.
- Enter `q` to quit during a round.
- Scores are tracked and the match ends when one side reaches the majority of rounds.
